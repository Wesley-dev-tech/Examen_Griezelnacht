# Griezelnacht Exam

My exam for the Fundamentals & tooling module during my developer training: a landing page for Griezelnacht, a fictional Halloween night at Kasteel Ravenhoek, rebuilt from a given design with HTML, CSS and Bootstrap.

## The Assignment

Convert the design to HTML and CSS using a CSS framework of choice (through a CDN), a custom external stylesheet, Flexbox, CSS variables and Google Fonts.

## Technologies Used

- HTML for the page content.
- CSS in the external stylesheet `styles.css`, with CSS variables for the colours and fonts.
- Bootstrap 5.3.3 for the responsive grid and the container.
- Flexbox for the header, buttons, info cards, newsletter form and footer.
- Google Fonts: Pirata One for the gothic titles, Special Elite for the typewriter text and Figtree for the body text.

## Features

- A header with the pumpkin logo, navigation and a ticket button.
- A hero with a purple glow, a glowing title and a layered illustration: the moon, a ghost, bats, a pumpkin with its shadow and the castle, each placed separately with absolute positioning.
- A subtle mist effect at the bottom of the hero.
- Info cards for the opening hours, age and attractions.
- A newsletter card with an orange gradient and an e-mail field.
- A footer with the address and links.
- A mobile layout with the menu on its own row and centered content.

## How to View

Live: https://wesley-dev-tech.github.io/Griezelnacht_exam/

Or download the files and open `index.html` in a browser. No installation or build step is required. An internet connection is needed to load Bootstrap and Google Fonts.

## Project Structure

- `index.html`: the page content.
- `styles.css`: the custom stylesheet.
- `images/`: the illustrations (moon, ghost, bat, pumpkin, castle and twig).
- `README.md`: project documentation.

## About This Version

This is a static frontend demo. The buttons and the newsletter form do not send or store anything, and there is no backend or ticket system. The event, the castle and the contact details are fictional content for the exam. No JavaScript is used.
